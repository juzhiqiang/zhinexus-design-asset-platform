## 验证范围

`/match` 页面已挂载设计 ID 配置、元素清单、可选绑定输入、装配方案展示，并保留人工文本检索。本次验证覆盖：

- 登录门与未登录不暴露配置；
- 空配置显示尚未配置，不称匹配成功；
- 规则 JSON 语法/未知字段/重复映射/重复实例本地拒绝，不发请求；
- 未知 designId 交服务端报缺口；
- 只有显式点击才 POST，请求体只含冻结契约字段，Bearer 取当前会话；
- 绑定 JSON 合法随请求发送，非法或引用不存在实例本地拒绝；
- 同一 designId 多实例独立成行；
- mapped 元素展示真实目标、证据、兼容状态、依赖；
- inputDigest 一致展示方案，不一致忽略旧响应；
- 空设计响应带 EMPTY_DESIGN 缺口；
- 401/403/5xx/非法响应只显示固定文案；
- 编辑规则/元素/上下文/绑定取消在途请求并清理结果；
- React DOM 精确版本随装配请求发送；
- 退出登录与换 token/storage 事件取消并清理；
- designId 仅按文本转义呈现；
- 窄屏 375px 不横向溢出；
- 界面不使用模型/OCR/视觉匹配表述，不持久化设计配置。
