## 缺陷与最小修复

共享 `validateIntegrationApplyResult(input, context)` 原先对所有 applied 结果无条件要求 exactDependencies 全量版本，误拒产品已存在的无安装分支；不带 context 时又允许 not-run 结果捏造非空版本列表。

本次增加无安装空列表正例、伪造安装列表反例、需要安装却缺实测结果反例及无安装谎称 succeeded 反例。结构 Schema 不变，仅对齐上下文与语义校验：

- no-install applied 必须 `not-run + []`；
- 计划含 lockfile-regeneration 时仍必须 succeeded 与精确全量安装版本，错版本、缺项、多项继续拒绝；
- project root、plan digest、完整写集、before/after guards、backup、失败恢复规则不变。

矩阵评分同步读取诚实 apply 结果，只在 apply succeeded 时比对其本次安装列表。verify 报告中的实际全量依赖、清单摘要以及错版本反例继续独立校验，未降低场景动作、预期、20个正向分母、13个强制拒绝或80%门槛。
