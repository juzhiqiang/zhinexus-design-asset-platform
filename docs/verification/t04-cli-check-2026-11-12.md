## 1. 交付内容与边界说明

1. **CLI 命令入口 (`packages/component-cli/src/commands/check.ts` 与 `cli.ts`)**:
   - 提供 `component check [--framework vue|react|all] [--staging-dir <dir>]` 完整参数解析与执行调度。
   - 默认执行双框架（Vue + React）全量检查；参数异常退出码为 1。
   - 脱离骨架阶段，按语义化版本将 `@company/component-cli` 升级至 `0.0.2` 并同步 `CHANGELOG.md`。

2. **公开包内联契约机制 (`packages/component-cli/scripts/sync-contracts.mjs`)**:
   - 遵循公开包边界规则，`@company/component-cli` 不在运行时 `dependencies` 依赖私有包 `@company/contracts`。
   - 构建阶段通过预处理脚本将 contracts 校验、schema 与核心类型内联到 `src/contracts/` 并编译，确保对外发布的 npm 产物自包含。

3. **工作区外干净消费者模板增强 (`tests/consumers/vue` 与 `tests/consumers/react`)**:
   - 在保留原有 `window.__CONSUMER_TEST__` 测试钩子的基础上，实现对等 `ComponentExample` 协议（`window.__COMPONENT_EXAMPLE__`）：
     - `ready`: Promise 异步等待字体 `document.fonts.ready`、容器有效正向几何尺寸（`width > 0 && height > 0`）与 ECharts 实例就绪。
     - `states`: 暴露所需状态枚举（`['default']`）。
     - `runState(name)`: 状态切换与渲染驱动。
     - `getChecks()`: 包含 `single-instance`、`no-page-error`、`valid-dimensions`、`fonts-ready`、`series-rendered`。
   - 监听全局 `error` 与 `unhandledrejection`，记录页面运行时错误。

4. **确定性截图采集器 (`packages/component-cli/src/local/capture.ts`)**:
   - 使用 Playwright Chromium 在无头模式下以固定配置运行（视口 800x400、deviceScaleFactor: 1、locale: zh-CN、timezone: Asia/Shanghai）。
   - 严格按照 `ready` → `runState` → `getChecks` 驱动；超时（默认 30s）抛出 `READY_TIMEOUT` 并失败退出。
   - 遇任何 `pageerror` 运行时错误立即抛出 `PAGE_ERROR`，断言有图也不能掩盖页面异常。

5. **环境指纹与签名 (`packages/component-cli/src/local/environment.ts`)**:
   - 采集并归一化 OS、架构、浏览器精确版本、字体指纹、区域与视图参数，生成符合 `EnvironmentV1` 规范的对象。
   - 计算规范化 JSON 序列化的小写 64 位十六进制 SHA-256 环境签名 (`environmentKey`)。

6. **报告生成与契约校验 (`packages/component-cli/src/local/report.ts`)**:
   - 生成 `CheckReportV1` 结构，强绑定当前执行所用的候选包 SHA-256 (`packageSha256`)。
   - 首轮无视觉基线时基线结果固定为 `NEW`（像素对比、基线接受与恢复在后续任务实施）。
   - 生成产物通过 `validateCheckReport` 契约校验后保存至暂存区 `reports/<id>.json`。
