## 1. 交付功能清单

### 1.1 组件资产目录列表 (`/components`)
- **发现页面**: 提供响应式组件卡片网格，卡片展示组件中文名（如折线图、柱状图、饼图、散点图）、英文名、分类、支持框架标签（Vue 3、React 19）、`Ready` 可用性状态及发布版本号。
- **筛选与搜索**:
  - 框架切换按钮：全部 / Vue 3 / React 19。
  - 即时搜索框：支持中文名称、组件标识、分类等多字段即时过滤。
- **边界与优雅降级**:
  - 当无公开资产或后端 API 离线时，页面展示友好空状态，保留原有“公开组件目录正在建设中”合规提示，同时提供官方预置规范浏览选项。

### 1.2 组件详情与双框架切换 (`/components/[slug]`)
- **路由与 404 保护**:
  - 动态路由覆盖 `line`、`bar`、`pie`、`scatter`。
  - 对未公开或未知组件（如 `/components/not-published`）严格返回 404（`notFound()`）。
- **双框架切换选项卡 (Vue 3 vs React 19)**:
  - 页面顶部提供 Vue 3 和 React 19 切换选项卡，支持一键切换。
  - 切换时同步更新：发布包名（`@company/charts-vue` vs `@company/charts-react`）、版本（`0.0.4`）、安装命令、ESM 导入语句、API 属性规范及预览 iframe 目标入口。

### 1.3 状态看板展示
- 严格遵循核心架构的状态正交分离原则，独立展示：
  - **可用状态 (Availability)**: `Ready`（绿色高亮，表明 tarball 与静态预览均可达）
  - **检查报告来源 (Report Source)**: `local-automatic`（本地 Playwright 自动化签名报告）
  - **视觉基线状态 (Baseline Status)**: `accepted`
  - **检索索引状态 (Index Status)**: `indexed`
  - **版本与引擎**: `@company/charts-vue@0.0.4` / `@company/charts-react@0.0.4`，Apache ECharts `6.1.0`。

### 1.4 沙箱隔离预览 iframe
- 嵌入 `<iframe className="preview-frame" sandbox="allow-scripts allow-same-origin" />`。
- 遵循沙箱隔离策略，在访问者浏览器的沙箱 iframe 中隔离运行，无凭证泄露风险，严禁访问平台管理 API。
- 顶部工具栏提供：实时就绪指示灯、独立域沙箱安全标识、800×400 视口指示与沙箱重新加载按钮。

### 1.5 代码集成与 API 规范
- 提供一键复制的依赖安装命令（`pnpm add ...`）。
- 展示标准 ESM 导入代码范式。
- 规范化表格呈现 Props 属性列表（名称、类型、必填/可选、说明）与 Events 事件列表。
- 展示全链路验证凭证（ECharts 6.1.0、Vue 3.5.45 / React 19.3.1 兼容性、冻结 tarball 验证）。
