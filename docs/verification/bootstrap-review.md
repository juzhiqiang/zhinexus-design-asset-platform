> 历史记录：本文审查发生于 Nest/React 调整前。当前实现与后续审查结果见 [Nest/React 验证记录](nest-react-bootstrap.md)。

## 审查发现

Critical：0；Important：1；Minor：0，无延后的小问题。

唯一 Important 为 Windows PowerShell 5.1 首次下载：原 `Invoke-WebRequest` 会进入确认流程，非交互执行失败；已有 `.tools` 的检查覆盖不到该分支。修复统一使用 `-UseBasicParsing`，并增加 `scripts/verify-bootstrap.ps1`，从干净隔离目录调用真实 Windows PowerShell，检查首次下载、摘要、固定版本和第二次缓存运行。

回归先在原脚本上失败，错误为 `Windows PowerShell is in NonInteractive mode. Read and Prompt functionality is not available.`。修复后的回归和完整验证结果记录在 [初始化验证](bootstrap.md)。独立审查不代表 G1/G2 或业务任务已经验收。

## 实施决定与代价

| 决定 | 理由 | 代价或判断错误的影响 |
| --- | --- | --- |
| 在用户指定目录初始化 Git | 起点没有 Git 仓库与既有开发分支 | 当前任务共用该目录；未来功能开发需各自分支/工作区 |
| Node/pnpm 固定版本安装到项目 `.tools` | 系统版本与所选版本不同，需可重复运行 | 首次联网下载与磁盘占用 |
| 只交付初始化子集，完整 T01 保持开放 | 用户本轮请求是初始化与分配，不是全部业务实现 | G1/G2 必须后续投入；骨架无法承担真实发布 |
| pnpm 12 使用原生 Windows 包和 YAML 设置 | 实际包入口及安装配置与旧示例不同 | 需要维护平台相关引导脚本 |
| 根 TS7、Vue SFC 检查隔离 TS6 | 已复现 vue-tsc/volar 的 peer 和编译器 API 不兼容 | 暂时维护两种编译器，后续升级需重新验证 |
| manifest、lockfile、`.node-version` 作为版本固定来源 | 避免再维护一份重复的 `versions.lock.json` | 版本发现与实际安装证据需分别核对 |
