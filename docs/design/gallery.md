# 组件画廊设计稿

用 pen.dev / Pencil 打开同目录的 [gallery.pen](gallery.pen)。画廊使用独立设计文件；管理后台的六张画板仍在 [management-api.pen](management-api.pen)，见 [管理控制台设计说明](management-api.md)。

00 是用户确认方向后新增的介绍首页概念稿，当前为第四版：保留第三版的钛金属数字雕塑、悬浮玻璃趋势光带与立体柱阵，改用清透冰蓝、钴蓝和鸢尾紫反射，避免灰雾感；纯黑底改为午夜蓝，并增加慢漂光场、稀疏微粒、首屏细轨道及局部游光，不沿用现有后台风格。01–03 仍为依据 `apps/gallery` 现有公开页面路由、文案和样式的静态还原，未随首页重设计。原有文字、图表、雕塑和表格均保留可编辑原生图层；新增五层可调 shader 装饰，PNG 仅为静态代表帧。

| 画板 | 参照页面 | 展示内容 | 尺寸 |
| --- | --- | --- | --- |
| 00 介绍首页 · 科技朋克 | `/`（概念，未实现路由） | 钛金属主视觉、资产展示、Vue/React 双框架、光纤接入流程与行动入口 | 1440 × 3196 |
| 01 组件目录 · 公开空状态 | `/components` | 目录建设中提示与浏览官方预置规范入口 | 1440 × 800 |
| 02 组件目录 · 官方预置规范 | `/components` | 框架筛选、搜索及折线/柱状/饼图/散点图四张卡片 | 1440 × 1120 |
| 03 折线图详情 · Vue 实现 | `/components/line` | 框架切换、独立状态项、预览、精确安装命令、Props/Events 和兼容性分区 | 1440 × 2199 |

画板沿水平方向排列，00–03 起点依次为 `(-1520, 0)`、`(0, 0)`、`(1520, 0)`、`(3040, 0)`。首页和详情页使用内容驱动的高度，保留完整长页；新增首页未移动原三张画板。

## 预览与范围

当前预览：[介绍首页 · 第四版](previews/2026-11-23/I0RAl-v4.png)、[清透图表 · 局部](previews/2026-11-23/hly06-v4.png)、[首屏氛围 · 局部](previews/2026-11-23/DkEmJ-v4.png)、[公开空状态](previews/2026-11-23/oBjp6.png)、[组件目录](previews/2026-11-23/BTiJR.png)、[组件详情](previews/2026-11-23/VyIbV.png)。01–03 未改变内部布局，沿用原导出预览；[首页第一版](previews/2026-11-23/I0RAl.png)、[第二版](previews/2026-11-23/I0RAl-v2.png)、[第三版全页](previews/2026-11-23/I0RAl-v3.png) 与 [第三版图表局部](previews/2026-11-23/hly06-v3.png) 保留用于历史追溯，不代表当前画板。

首页包含顶部导航、原生矢量 Möbius 金属雕塑、技术生态横带、不对称双图表展示、双框架金属徽章、四步光纤接入流程、最终行动区和页脚。首页有 2184 个命名可编辑图层，其中雕塑由 1860 个复合路径构成；资产展示分区有 186 个图层，包含玻璃光带、聚焦注释、金属柱的独立顶面/侧面/倒角/反射、浮空底台和底层氛围装饰。没有位图、待生成图片或外部图片依赖。图表数字均为设计示意。导航、筛选、沙箱预览与按钮仅为静态视觉，不代表新增交互或已完成业务验收。

五个背景层共同引用 [gallery-atmosphere.glsl](shaders/gallery-atmosphere.glsl)，通过 `@time` 驱动慢漂；各层 `u_mode` 区分构图，`u_speed=0` 可手动冻结，`u_frame` 选择静止帧。复制设计时须同时保留 `gallery.pen` 和相邻 `shaders/` 目录；每层另有午夜蓝纯色兜底。导出的 PNG 不会播放动效；本轮不包含应用动画实现、系统减少动态效果偏好接入或完整 Pencil 播放性能验收。

02–03 的包版本 `0.0.4` 与状态取自 `apps/gallery/app/lib/catalog.ts` 的内置规范示例，不代表真实发布、Ready 可达性或兼容性验收通过。03 展示预览授权及兼容性来源暂不可用时的状态，保留 React 切换入口，但不包含 React 切换后的独立详情画板或移动端画板。
