# 管理控制台与画廊设计稿

用 pen.dev / Pencil 打开同目录的 `management-api.pen`。画板以画廊现有页面的路由、文案和样式为参照，展示桌面布局。账号、域名、作业及审计记录均为示例数据。

| 画板 | 参照页面 | 展示内容 |
| --- | --- | --- |
| 01 上传发布 | `/upload` | 导入预构建产物、逐实现截图必检、缺图时禁用提交 |
| 02 发布作业 | `/jobs/[jobId]` | `PUBLISHING` 状态及五个推进检查点 |
| 03 接入设置 · 公司登录 | `/access-settings` | OIDC 草稿、验证、恢复和审计 |
| 04 接入设置 · 预览入口 | `/access-settings` | 预览地址、隔离检查、恢复和审计 |
| 05 用户与权限 | `/users` | 创建成员、角色与资产授权、账号操作和审计 |
| 06 项目上下文匹配 | `/match` | 项目上下文、文本检索、精确查询和设计 ID 匹配 |
| 07 组件目录 · 公开空状态 | `/components` | 目录建设中提示与浏览官方预置规范入口 |
| 08 组件目录 · 官方预置规范 | `/components` | 框架筛选、搜索及折线/柱状/饼图/散点图四张卡片 |
| 09 折线图详情 · Vue 实现 | `/components/line` | 框架切换、独立状态项、预览、精确安装命令、Props/Events 和兼容性分区 |

07–09 于 2026-11-23 补充，位于原有六张管理画板右侧。08–09 的包版本与状态取自 `apps/gallery/app/lib/catalog.ts` 的内置规范示例，不代表实际发布或验收结果。09 展示预览授权及兼容性来源暂不可用时的页面状态。所有文字、卡片和表格均为可编辑图层；PNG 只用于预览。
