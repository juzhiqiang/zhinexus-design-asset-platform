# 管理控制台设计稿

用 Pencil 打开同目录的 `management-api.pen`。画板以画廊现有控制台的路由、文案和样式为参照，展示桌面布局。账号、域名、作业及审计记录均为示例数据。

| 画板 | 参照页面 | 展示内容 |
| --- | --- | --- |
| 01 上传发布 | `/upload` | 导入预构建产物、逐实现截图必检、缺图时禁用提交 |
| 02 发布作业 | `/jobs/[jobId]` | `PUBLISHING` 状态及五个推进检查点 |
| 03 接入设置 · 公司登录 | `/access-settings` | OIDC 草稿、验证、恢复和审计 |
| 04 接入设置 · 预览入口 | `/access-settings` | 预览地址、隔离检查、恢复和审计 |
| 05 用户与权限 | `/users` | 创建成员、角色与资产授权、账号操作和审计 |
| 06 项目上下文匹配 | `/match` | 项目上下文、文本检索、精确查询和设计 ID 匹配 |

## 验证

在 Pencil 中使用 `TakeScreenshot` 逐页检查，并使用 `Get` 检查布局诊断和图层数量。六张画板均无裁切诊断、无未完成占位，上传清单有 14 条实现记录。`save` 成功，且本地 `.pen` 文件非空。本次验证覆盖静态画稿，未进行浏览器行为或 API 集成测试。
