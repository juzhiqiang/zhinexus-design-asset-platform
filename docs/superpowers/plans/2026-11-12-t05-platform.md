# T05 平台身份、上传与产物校验执行计划

基线：`6993e11`。用户授权在新分支开发 T05，完成后提交并合并本地 main；不包含 push。分支 `feat/t05-platform`，复用当前隔离工作树。负责人 C。

## 范围和决定

实现 Nest HTTP 身份验证、PostgreSQL 业务迁移、MinIO 上传/分片/冻结校验、发布创建/读取、基线权限/CAS、废弃和 append-only 审计。真实 OIDC/DNS 资源尚缺：交付可配置的 OIDC JWT/JWKS 验证器，以真实签名测试身份验证正反例；无配置时受保护接口拒绝访问。G2 和完整 T05 外部身份验收保持未完成，不使用开发后门。

服务端只解析预构建字节，不 install、build、import 上传代码，不启动截图浏览器。T06 worker 不在本轮，合法创建的作业持久化为 PENDING，不自动发布或 Ready。组件负责人由数据库管理，subject 只来自验证后的 access token。

上传入口保留现有请求。响应以兼容可选字段补充分片 URL 列表，complete 使用现有 parts。<=10 MiB 单 PUT，其余按 5 MiB 分片；URL 15 分钟，会话 24 小时。complete 重新读取字节、校验声明并另存服务器独占的冻结对象，之后验证/创建作业只读取冻结对象，原 signed URL 再写不会改动已验证材料。失败关闭，完成有租约/fencing 防并发旧写入。

共享限制：单包 50 MiB、单图 10 MiB、边长 8192、受限 tar 展开 200 MiB/5000 文件、总材料 500 MiB。截图支持真实解码 PNG/JPEG，不接受 SVG。tar 仅解析文件到内存，不写出解包目录，拒绝软/硬链接、穿越、碰撞和炸弹。文件来源与完整清单、报告、实际 package.json/exports/dependencies 一并核对。

错误码沿用当前 contracts 的 SCREENSHOT_REQUIRED / SOURCE_FORBIDDEN 等稳定值，替代早期任务说明中的示例别名。web 客户端身份只能提交 web/manual-upload，拒绝伪造 cli/local-automatic；CLI 来源只表示客户端声明。

## 验收边界

运行时 JWT 正反例和本地三存储测试不能替代公司 OIDC 网页/CLI 实际登录、回调、权限撤销和 A/B 回执；本轮代码可交付并合并，但 T05 完整外部验收不得打勾。T06 状态机/发布、T07 网关和前端网页提交由后续任务实现。
