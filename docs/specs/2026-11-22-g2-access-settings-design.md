# 公司 OIDC 与预览入口后台配置

当前平台从环境变量读取 OIDC 验证参数和预览入口，画廊预览模式在构建时写入。现有接入脚本能检查 OIDC 元数据和入口可达性。公司网页登录、CLI 登录、实际撤权和逐发布域的 DNS/TLS 仍待验收。目标是让平台管理员通过后台维护并验证这些配置，使用 IP 模式起步，域名准备就绪后在后台切换应用入口。

## 管理员工作流

在画廊控制台提供「接入设置」，分为「公司登录」和「预览入口」。各区显示生效版本、草稿、验证时间和未通过的步骤。管理员可以保存草稿、运行检查、启用通过验证的版本，并恢复此前有效的版本。修改草稿后需要复验被修改的项。发布和回退按配置版本写入审计，至少记录操作者、时间、结果和版本，支持比较非密钥字段。

两区可以分别启用。平台同时使用一个生效的公司 OIDC issuer。现有环境配置作为迁移和首次启动来源，使用后台启用过的配置后由数据库活动版本决定应用行为。平台管理员按部署登记的 OIDC issuer 和 subject 授权，与组件 maintainer 独立。首次设置和身份服务不可用时，运维通过部署侧受控命令设置或恢复已验证的版本。管理员提交验证、启用和回退时由 API 再次校验管理员权限。

## 公司登录

支持配置 issuer、API audience、网页与 CLI 客户端 ID、回调、用于业务角色的声明映射和服务端密钥引用。服务端从 issuer 获取 Discovery 和 JWKS，核对元数据、签名和允许的客户端。密钥保留在现有部署环境或密钥管理中。页面显示密钥引用是否可用。

网页接入授权码与 PKCE，在后台候选验证入口用实际测试账号跑完整回调。平台验证 state、nonce、令牌签名、issuer、audience 和客户端，在服务端建立会话。CLI 使用对应的公开客户端，以 PKCE 和本机回环完成登录并调用受保护 API。沿用现有发布命令显式传入 access token 的兼容入口。候选登录仅可使用验收沙箱能力，直到配置启用。切换 issuer 时旧会话失效，已有组件授权和平台管理员身份按 issuer 与 subject 隔离。需要迁移时，运维显式绑定同一人的新身份。

后台分别记录 Discovery、真实 Web/CLI 登录、业务角色和撤权结果。撤权以公司侧实际停用测试账号或移除测试角色为触发。公司身份同步更新平台现有的停用和授权记录。验收请求要覆盖已签发 access token、现有 Web 会话、已有预览授权和再次获取权限行为，记录从公司侧变更到平台拒绝的时间。账号停用与单项角色撤销各有独立断言。目标时限由公司身份管理员提供并记录在验收环境。平台先沿用现有停用和授权数据作为撤权接口边界，真实同步协议由公司身份系统提供。管理员可在候选配置通过真实登录和权限核对后启用，正式 G2 的身份接入通过还需要真实撤权证据。仅等待旧令牌过期、仅使用模拟身份源、只读元数据或缺公司同步时，真实撤权保持待验证。撤权验收使用专用测试账号。

## 预览入口

支持选择「同 IP 分 HTTPS 端口」和「独立预览域」。后台可改预览地址并验证候选。画廊与 API 的外部入口作为部署提供的信任边界参与校验。沿用现有 origin 验证、域模式逐发布主机和 IP 模式不透明沙箱。切换后画廊按每次授权的 origin 和对应隔离模式打开 iframe，无需为切换重建画廊。API 与网关在签发和兑换时用相同活动版本验证配置。旧配置签发的授权按版本失效，画廊重新申请。回退前复核旧入口的 DNS、证书与路由。公司登录回退时复验管理员能通过恢复后的入口进入。

域名模式从至少两个符合逐发布命名规则的实际主机验证 DNS 通配解析、预期网关可达性、TLS 主机名、信任链和有效期。检查需要区分解析失败、连接失败、证书不匹配或不受信任、入口路由不匹配。IP 模式核对独立端口、可信证书链、证书 IP SAN 和网关可达性。预览授权、隔离和撤销走已有本机浏览器验收路径。平台服务只提供静态资源，浏览器验收在验收客户端执行。

后台切换的是平台使用的地址和隔离模式。DNS 记录、证书签发与续期、入口监听和密钥挂载沿用部署侧配置。候选入口由运维先设好，后台验证后启用，使平台切换和 DNS/TLS 的部署时序可以分开。支持保留原 IP 配置供回退。后续需要平台代管 DNS 或证书时，再按公司供应商及权限单独定义接口。

## 实现与验收约束

- 在 contracts 定义配置、探测结果和预览授权所需的运行时字段。C 负责数据库、权限、验证与网关，B 负责画廊控制台、Web/CLI 登录入口和浏览器验证。原始架构文档保持只读，实施计划和部署说明随实现同步。
- 启用操作用 PostgreSQL 原子更新活动版本，拒绝基于旧版本的写入。可用前版本保留为回退目标。缓存仅存放已验证配置内容，签发或兑换授权时仍核对活动版本。无法确认版本和授权有效时拒绝请求。启用结果明确显示 API 和网关是否已接受新版本。
- OIDC 端点与预览探测必须落在部署允许的出站主机、端口和网络范围内，校验解析后的地址，检查时限、响应上限并拒绝重定向越界。OIDC 验证请求和预览探测都不得回显 token、Cookie、密钥或授权地址。实际用户登录以正规公司身份回调为准。
- 本地自动化使用隔离 IdP 和 TLS 域，覆盖首次启动、权限拒绝、草稿校验、启用、并发写入、回退、已有授权失效和审计脱敏。用已有发布资产验证 IP 到域名切换和双框架预览。公司环境记录实际 Web/CLI 登录、撤权时限及发布域 DNS/TLS 的脱敏证据。公司资源未提供时，实际验收状态保持待验证。
