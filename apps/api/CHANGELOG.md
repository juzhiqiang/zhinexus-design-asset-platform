# @company/platform-api 更新日志

## [0.0.11] - 2026-11-22

### 新增

- 接入配置草稿、不可变版本、逐项验证证据、活动代数、管理员 CAS 启用与经验证恢复；管理权限独立于业务角色。

- 受限 HTTPS 固定核验地址并支持公司 CA；预览入口检查与网关活动代数确认。

- 验签后及业务写入事务核对认证代数；撤权、旧会话、旧角色授权、遗漏接入配置及过期候选票据失败关闭。鉴权拒绝记录脱敏审计。
