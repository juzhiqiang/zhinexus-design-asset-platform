# @company/preview-gateway 更新日志

## [0.0.6] - 2026-11-27

### 修复

- 授权兑换与静态资源读取支持匿名公开预览授权（`subject IS NULL` 且 `read_roles` 为空），持续通过 `preview_can_read(variant_release_id, subject)` 在每次请求核验公开状态、Ready 状态与预览代数，组件转私或版本废弃后立即拒绝访问。
- 仅在非生产且非 `0.0.0.0` 的本地回环开发环境且存在数据库与对象存储配置时启用 `127.0.0.1:3001` 默认回环预览配置。

## [0.0.5] - 2026-11-22

### 新增

- 授权兑换与资源请求均核验自管账号状态与签发时的账号版本，旧版本或已停用账号拒绝访问；只读取必要的账号状态与版本字段。


## [0.0.4] - 2026-11-22

### 新增

- 与 API 共读预览活动配置和代数，提供只读入口探针并确认实际网关配置；切换和恢复后拒绝旧预览授权及会话。
- 部署说明增加受限数据库授权及域名/IP 入口凭据过滤模板。

### 修复

- 预览兑换和资源读取按签发时有效角色核对撤销；迁移后的旧授权缺少角色来源时拒绝使用。
