# @company/admin 更新日志

## [0.0.10] - 2026-11-27

### 新增

- 「资产管理（`/assets`）」补齐分类筛选、分页、历史与已废弃（`DEPRECATED`）版本切换、组件公开/内部私有可见性切换、自动携带 `expectedRevision` 的视觉基线二次更新、隔离沙箱在线预览、受保护截图原图、文档与 API 参数/事件契约查看、检查报告明细及 ECharts 兼容实测证据登记。
- 「成员与权限（`/users`）」补齐服务端分页、组件只读（`canRead`）授权、已知组件与包候选补全、密码不确定态锁定提示；顶栏新增自管账号自助修改密码弹窗与 UUID/关键词智能快速搜索。

### 修复

- 修复发布作业列表 `PUBLISHING` 状态筛选与作业详情页 `RETRY_WAIT` 重试入口条件，补齐 `READY` 态基线候选与资产跳转；同步修复后台渲染与样式完整性单测。

## [0.0.2] - 2026-11-24

### 新增

- 管理员维护稳定分类、名称、启停和修订；CAS 冲突保留草稿并提示显式刷新。
- 发布选择现有框架实现与分类，同一冻结包的实现联动选择，逐实现手动截图与原 ACL 校验继续执行。

### 修复

- 身份/API 切换与 401/403 拒绝后，迟到请求不能恢复旧私有分类、草稿或权限；发布选项预检失效时清理旧 ACL 并保留材料/恢复会话。

## [0.0.1] - 2026-11-24

### 新增

- 从公开画廊拆分内网管理端，承载发布、作业、匹配、账号和接入设置。
